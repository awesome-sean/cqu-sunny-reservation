重庆大学天气预约提醒｜安卓版使用说明

用途：查看北京时间后天的天气；白天预报为“晴”时，提醒预约。
例如：22 日检查 24 日的天气，并提醒预约 24 日。
天气来自 UAPI 的重庆沙坪坝区预报，并非校内独立观测。
点击预约通知或正常状态的小组件可打开预约网页，预约需自己完成。

一、安装应用与脚本
1. 下载并安装 Scriptable Android（支持 Android 8.0 及以上）：
https://github.com/awesome-sean/scriptable-android/releases/download/v0.2.2/Scriptable-Android-0.2.2.apk
2. 打开应用，点脚本页搜索框右侧的导入按钮（向下箭头）。
3. 选择随附的“重大天气提醒.js”。此脚本需单独导入，不在应用内置示例中。
4. 打开脚本，点“运行”，可看到天气小组件预览。

二、开启运行权限
1. 点底栏“自动化”，查看页首的“先完成运行设置”。
2. 允许通知，开启精确定时权限。
3. 按手机系统要求允许后台运行、自启动，并取消对此应用的电池限制。
4. 如需横幅或声音，在系统的应用通知设置中开启，并检查勿扰模式。
本天气脚本使用固定地区，不需要定位权限。

三、设置每天自动提醒
1. 点底栏“自动化”→“新建”。
2. 名称填写“重大天气提醒”，执行脚本选择“重大天气提醒”。
3. 每天运行时间按需填写，如 09:00；多个时间用英文逗号分隔，如 09:00,18:00。
4. 时区填写：Asia/Shanghai
5. 脚本参数填写：notify
6. 打开“启用定时执行”，点“保存”，确认“下次”时间正确。

设置后可返回桌面或锁屏等待，不要强行停止应用。
后天白天不是“晴”时，不发预约通知，属于正常情况。
同一天多次执行，只要条件满足，每次都会提醒。

四、添加桌面 2×2 小组件（可选）
1. 打开天气脚本，点“运行”生成小组件预览。
2. 使用预览中的添加入口；也可长按桌面空白处→小组件，找到 Scriptable Android。
3. 添加后选择“重大天气提醒”脚本，内容尺寸选“小 · 默认”，参数留空，保存。
4. 默认申请 2×2；不同手机桌面可能需要长按调整大小。
小组件预览和桌面刷新不会发送预约通知；通知由第三部分的自动化触发。

五、验证定时通知（可选）
1. 导入随附的“定时通知测试.js”，先手动运行，确认能收到通知。
2. 新建自动化，执行脚本选“定时通知测试”，时间设为当前时间之后 3～5 分钟。
3. 时区填写 Asia/Shanghai，参数留空，启用并保存。
4. 返回桌面等待，到点收到的通知应显示“触发方式：后台自动化”。
5. 测试结束后关闭或删除此任务，避免每天重复提醒。
测试脚本不判断天气、不联网，只验证定时执行和通知。

没有收到提醒时：
查看自动化的最近运行时间和“结果”，再检查通知、精确定时、后台运行与省电设置。
“已完成”只表示脚本执行结束，不代表一定发送了通知。
系统省电和厂商后台策略可能导致延迟；天气查询还需要网络正常。
