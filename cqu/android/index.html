安卓设置教程

安装 Scriptable Android，导入天气脚本，在应用内设置定时提醒。

下载通知测试脚本

1. 下载应用与脚本

  1. 打开 Scriptable Android 下载页，下载 Scriptable-Android-0.2.3.apk。
  2. 打开 APK，按系统提示允许安装。支持 Android 8.0 及以上。
  3. 下载 安卓天气脚本 cqu-weather.js。
  4. 打开应用，点脚本页搜索框右侧的 导入按钮（向下箭头），选择该 JS 文件。
  5. 导入后打开脚本，点 运行，确认能显示天气预览。脚本在应用中显示为文件名时，可通过脚本菜单将其改名为 重大天气提醒。

天气脚本需要单独导入，未打包进 APK 的内置示例。应用安装、版本更新与源码说明请看 软件下载说明。

2. 先完成运行设置

点底栏 自动化，按页首“先完成运行设置”的说明操作：

  • 通知：允许应用发送通知；需要横幅、声音时，在系统通知设置中开启。
  • 精确定时：允许应用按设定时间触发任务。
  • 后台运行：按手机系统要求开启自启动、允许后台运行，并检查电池限制。

此脚本使用固定地区，不需要定位权限。不同品牌的后台设置名称不同，以手机实际页面为准。

3. 新建每天的天气提醒

点 新建，按下表填写：

项目 填写内容
名称 重大天气提醒
执行脚本 选择刚导入的安卓天气脚本
每天运行时间 例如 09:00；多个时间可填 09:00,18:00
时区 Asia/Shanghai
脚本参数 notify
启用定时执行 打开

点 保存，确认显示的“下次”时间正确。可以返回桌面或锁屏等待，不要强行停止应用。可点“运行一次”检查脚本，然后查看任务的“结果”。

后天不是晴天时不发预约通知，属于正常情况。“已完成”只表示脚本执行结束，不代表一定发送通知。

4. 添加桌面小组件（可选）

  1. 运行天气脚本，生成小组件预览。
  2. 使用预览中的添加入口；也可长按桌面空白处 → 小组件，选择 Scriptable Android。
  3. 选择天气脚本，内容尺寸选 小 · 默认，参数留空，保存。
  4. 默认申请 2×2；最终占位由手机桌面决定，必要时长按调整大小。

小组件只展示天气与预约入口。通知由第三步的自动化触发，两者分别设置。

鸿蒙 5 及以上的部分兼容环境可能无法添加安卓桌面小组件。可先从桌面组件列表手动查找；如果没有入口，当前环境暂不支持该组件。后台定时通知也应单独测试，不能仅根据能安装、能导入脚本就判断可用。

5. 验证定时通知

现在不是晴天也能测试。通知测试脚本不联网、不判断天气，每次执行都提交一条通知。

  1. 下载并导入 通知测试脚本，先手动运行，确认能收到通知。
  2. 新建自动化，执行脚本选刚导入的测试脚本，参数留空。
  3. 时间设为当前时间之后 3～5 分钟，时区为 Asia/Shanghai，启用并保存。
  4. 返回桌面等待；到点通知应显示“安卓后台自动化”和实际时间。
  5. 测试结束后关闭或删除任务，避免每天重复提醒。

常见问题

运行后没有预约通知怎么办？

天气脚本只有在后天白天预报严格为“晴”时才发预约通知。还要确认参数填写 notify、网络可用，并已允许通知。

手动通知正常，定时却没收到？

先用测试脚本验证。iPhone 检查是否选择“立即运行”；安卓检查精确定时、自启动、后台与电池限制。返回自动化查看最近执行时间和结果。

有通知，但没有横幅或声音？

在系统的应用通知设置中检查横幅、声音和勿扰模式。提交通知不等于系统一定显示横幅。

小组件显示未更新？

检查网络，重新运行脚本查看错误。小组件不会用伪造天气代替查询结果。

预报使用重庆市沙坪坝区数据，不是校园独立观测。本项目只做提醒，预约需自行完成。实际开放日期与时间以学校预约页面为准。系统调度和省电策略可能造成延迟。
