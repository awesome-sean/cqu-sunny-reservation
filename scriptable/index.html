Scriptable Android

在安卓手机上运行 JavaScript，创建桌面小组件，让脚本按设定的时间自动执行。

下载与安装

  1. 点上方“下载 APK”，保存 Scriptable-Android-0.2.3.apk。
  2. 打开文件，按系统提示允许浏览器或文件管理器安装应用。
  3. 安装后打开 Scriptable Android，新建或导入 .js 脚本，再点“运行”。

支持 Android 8.0 及以上，无需解压。天气预约脚本需另外导入，见 安卓天气教程。

这个版本修复了什么

  • 修复粘贴长脚本时的卡顿。长脚本使用轻量纯文本编辑，保留全部代码、自动换行和保存能力。
  • 超过原有 1 MB 保存上限时明确提示，保留当前内容。
  • 优化光标与排版计算，小组件添加失败时使用中文说明。

软件支持脚本编辑、运行结果、定时自动化和桌面小组件。编辑器可调整字号，运行结果上方的横条可拖动调整高度。

从一个脚本开始

  1. 在脚本页点 ＋ 新建，或点向下箭头导入 JS 文件。
  2. 打开脚本，点 运行，按需完成权限授权。
  3. 需要定时执行时，进入底栏 自动化，先完成通知、精确定时和后台运行设置，再新建任务。
  4. 需要小组件时，先运行含 ListWidget 的脚本并生成预览，再添加到桌面。

后台调度受手机省电与厂商策略影响；小组件能否添加还取决于桌面或兼容环境的支持。

后续更新

当前 APK 的应用内“检查更新”通过 GitHub 获取版本信息。若网络无法连接，可返回本页下载已发布的新版本并覆盖安装。正式版本沿用固定签名，脚本与配置可保留。
